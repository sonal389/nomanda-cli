Version: 1.0.0

DESCRIPTION

Novenda CLI is a powerful command-line interface developed by
Novenda Technologies to simplify software development,
project management, AI integration, deployment, and automation.

The CLI provides developers with a fast, secure, and scalable
environment for building modern applications.

COMMANDS

novenda init
    Create a new project.

novenda dev
    Start the development server.

novenda build
    Build the application.

novenda deploy
    Deploy the project.

novenda login
    Authenticate your account.

novenda logout
    Log out of your account.

novenda update
    Update Novenda CLI.

novenda doctor
    Diagnose configuration issues.

novenda config
    Configure project settings.

novenda plugins
    Manage plugins.
